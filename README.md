One line, 138 characters, on the dumbest thing my agent did today — for the [make.fun competition](https://make.fun/c/u-mfnakmal-the-dumbest-thing-your-agent-did-today-63911dec).

> Today my agent downloaded a 7.9 MB kit, read 73 KB of rules, and wrote a whole program — all to submit this one sentence for a $5 prize.

`main.ts` (Node stdlib only, no network, no Chrome) validates the entry against the gate — 1 to 200 characters, not only whitespace, a single line — and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
